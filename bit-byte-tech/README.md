# Bit Byte Tech: website

A one-page website for Bit Byte Tech (computer and laptop repairs, upgrades and custom PC builds). It is a static site (HTML, CSS and a little JavaScript) with no server or build step needed to host it.

- **Domain:** https://www.bitbytetech.co.za (`bitbytetech.co.za` redirects to `www`)
- **Content:** from the client's three posters in `assets/references/`

## Files

| Path | What it is |
|---|---|
| `index.html` | The website (generated by `build.py`) |
| `404.html` | "Page not found" page, with homepage, free-quote and WhatsApp buttons (not indexed by Google) |
| `styles.css` | Design. Colours are variables at the top. |
| `main.js` | Mobile menu and the quote form (Formspree) |
| `build.py` | Builds `index.html`, `404.html` and `sitemap.xml` from shared parts and content |
| `robots.txt`, `sitemap.xml` | Search engine files |
| `site.webmanifest`, `favicon.ico`, `apple-touch-icon.png`, `assets/img/icon-*.png` | Browser and phone icons |
| `_headers` | Cloudflare Pages: HSTS, security headers and caching |
| `assets/fonts/` | Self-hosted fonts: Exo 2, Manrope, Yellowtail, Courier Prime |
| `assets/references/` | The client's posters. These are not needed on the live site. |

**To edit:** change the text in `build.py`, then run `python3 build.py`. Do not edit `index.html` by hand; it is overwritten.

## Quote form (Formspree)
The form sends to `https://formspree.io/f/xaeerwne`, set in `FORM_ENDPOINT` at the top of `main.js`.
- **Delivery:** messages go to the email address that owns the Formspree form.
- **Activation:** the first live submission sends a confirmation email to that address. Click the link in it to activate the form.
- **Spam:** a hidden spam-trap field blocks simple bots.

## SEO

### In the `<head>` of `index.html`
- **Title (54 characters):** "Computer & Laptop Repairs & Gaming PCs | Bit Byte Tech"
- **Meta description (148 characters):** includes the services, "CompTIA A+" and the phone number.
- **Other tags:**
  - meta keywords;
  - `robots: index, follow`;
  - canonical `https://www.bitbytetech.co.za/`;
  - theme colour.
- **Sharing tags (WhatsApp, Facebook, X):**
  - Open Graph with absolute URLs, plus image size and alt text;
  - Twitter/X card;
  - share image: `assets/img/og.jpg` (1200×630).

### Schema (JSON-LD)
- `ProfessionalService`: Bit Byte Tech, with phone, email, contact point, slogan, `knowsAbout`, and an `OfferCatalog` of 8 services.
- `WebSite` and `WebPage`.
- `FAQPage`: the 8 questions in the FAQ section, so they can show as rich results.

### On the page
- **One H1.** It includes the keywords: "Computer & laptop repairs · Upgrades · Gaming PC builds / Computer giving you trouble?"
- **Headings with search terms:**
  - "Professional computer & laptop repair services";
  - "Computer repairs, upgrades and custom PC builds";
  - "Custom gaming PCs and workstations, built to your budget";
  - "Computer repair questions, answered".
- **Images:** every image has alt text and a width and height (no layout jumps).

### Speed
- Self-hosted fonts, preloaded. No Google Fonts and no third-party scripts apart from the form submission.
- The hero logo is served at the right size (`srcset`, 44 KB on phones, 97 KB on desktop) and preloaded.
- CSS and JavaScript are single small files. The JavaScript is deferred.
- `_headers` caches assets for a year.

### Not set up yet (needs the client's information)

- **Google Analytics 4:** add the GA4 tag to `head()` in `build.py` once there is a measurement ID.

## Going live (Cloudflare Pages)
1. **Upload:** create a Pages project and upload this folder, or connect the GitHub repository with `bit-byte-tech` as the root. There is no build command.
2. **Domain:** add `www.bitbytetech.co.za` and `bitbytetech.co.za` as custom domains.
3. **HTTPS and www:**
   - SSL/TLS > Edge Certificates: turn on **Always Use HTTPS**.
   - Rules > Redirect Rules: send `bitbytetech.co.za/*` to `https://www.bitbytetech.co.za/${1}` (301).
4. **HSTS:** already sent by `_headers`.
5. **Search Console:** after launch, add the site in Google Search Console, submit `https://www.bitbytetech.co.za/sitemap.xml`, and request indexing.
6. **Google Business Profile:** create or claim one with the same name, phone number and website. For a local business, it brings in more calls than the website alone.
7. **Test the form:** send a test enquiry from the live site and confirm the Formspree activation email.

If the domain ever changes, update `DOMAIN` in `build.py`, `robots.txt` and `site.webmanifest`, then run `python3 build.py`.
